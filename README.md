# AI Lead Qualifier

AI-система квалификации лидов, интегрированная с Bitrix24.

Проект автоматически анализирует сообщения клиента, извлекает структурированные данные о сделке, накапливает состояние квалификации, рассчитывает показатели сделки и определяет следующий шаг для менеджера.

Основной сценарий проекта — квалификация входящих лидов для компании Best Paints.

## Что решает система

Менеджеру не нужно вручную перечитывать всю историю общения с клиентом и переносить ключевую информацию в CRM.

AI анализирует входящие данные и помогает поддерживать актуальное состояние сделки:

- извлекает данные о клиенте и проекте;
- определяет намерение клиента;
- определяет приоритет объекта;
- формирует краткое резюме клиента;
- выявляет боли и ожидания;
- определяет red flags;
- показывает недостающие данные;
- рассчитывает квалификационные оценки;
- определяет следующий шаг;
- сохраняет результат обратно в Bitrix24.

AI не принимает решение вместо менеджера. Он формирует дополнительный информационный слой поверх сделки, а итоговые действия остаются за человеком.
