# AI Lead Qualifier

AI-движок для автоматической квалификации лидов.

Система анализирует коммуникацию клиента, превращает неструктурированную информацию в данные CRM, накапливает состояние сделки, пересчитывает квалификацию и рекомендует менеджеру следующий шаг.

В текущем MVP используется **Bitrix24** и профиль компании из сферы подготовки и покраски деревянных домов.

Архитектура квалификации отделена от CRM-интеграции и бизнес-профиля, поэтому подход можно адаптировать под другую CRM и другую нишу.

## Что решает система

В реальном процессе информация о клиенте появляется постепенно: сообщения, звонки, фотографии и другие материалы. Менеджеру приходится самостоятельно собирать из этого целостную картину сделки.

AI Lead Qualifier автоматизирует эту часть процесса:

- анализирует сообщения клиента;
- принимает данные из CRM Open Line;
- расшифровывает аудио через Yandex SpeechKit;
- извлекает структурированные данные о клиенте и объекте;
- сохраняет накопленное состояние квалификации;
- определяет Intent и приоритет объекта;
- рассчитывает AI Score и качество лида;
- показывает Missing Data — каких данных не хватает;
- выявляет Red Flags, боли и ожидания клиента;
- формирует краткое резюме сделки;
- определяет Next Step — рекомендуемое действие менеджера;
- записывает результат обратно в CRM.

### Continuous Qualification

Ключевой принцип проекта — **не разовая оценка лида, а непрерывная квалификация**.

Каждая новая коммуникация дополняет уже известное состояние сделки. После появления новых данных система повторно рассчитывает квалификацию и обновляет результат.

```text
Сообщение клиента
       ↓
Новые факты
       ↓
Обновление состояния сделки
       ↓
Пересчёт Score / Intent / Missing Data
       ↓
Новый Next Step
```

## AI + бизнес-логика

AI отвечает за анализ коммуникации и извлечение информации.

Отдельный детерминированный слой бизнес-логики отвечает за квалификацию, scoring, проверку обязательных данных и выбор следующего действия.

Это позволяет не передавать модели принятие бизнес-решения целиком: менеджер получает рекомендацию, а окончательное решение остаётся за человеком.

## Архитектура

Текущий MVP построен вокруг Bitrix24, но ядро квалификации не зависит от конкретной CRM.

```text
                    Bitrix24
                       │
             ┌─────────┴─────────┐
             │                   │
          Open Line           Timeline
             │                   │
             └─────────┬─────────┘
                       │
              Text / Audio input
                       │
             ┌─────────┴─────────┐
             │                   │
        Text analysis      Yandex SpeechKit
             │                   │
             └─────────┬─────────┘
                       ↓
                GigaChat Analyzer
                       ↓
               Structured AI data
                       ↓
              Qualification State
                       ↓
                  Field Merger
                       ↓
             Qualification Pipeline
                       │
          ┌────────────┼────────────┐
          ↓            ↓            ↓
       Scoring    Missing Data   Red Flags
          │            │            │
          └────────────┼────────────┘
                       ↓
                Next Step Engine
                       ↓
             QualificationResult
                       ↓
                 Bitrix24 write
```

## Что попадает в квалификацию

В зависимости от профиля система может извлекать, например:

- тип объекта;
- материал;
- размеры / площадь;
- географию;
- состояние объекта;
- проект;
- фотографии;
- желаемый результат;
- дополнительные работы;
- желаемые сроки;
- бюджет;
- предыдущий опыт;
- Intent;
- приоритет объекта;
- боли и ожидания клиента;
- Red Flags.

Набор полей и правила scoring задаются профилем бизнеса, а не зашиваются в само ядро квалификации.

## Результат для менеджера

В CRM менеджер получает дополнительный информационный слой поверх сделки:

| Показатель | Что показывает |
|---|---|
| **AI Score** | Числовая квалификационная оценка лида |
| **Quality** | Итоговое качество лида |
| **Intent** | Насколько явно клиент готов покупать |
| **Missing Data** | Каких важных данных пока не хватает |
| **Red Flags** | Факторы, требующие внимания |
| **Next Step** | Рекомендуемое действие менеджера |

AI не принимает решение вместо менеджера. Он помогает быстрее понять текущее состояние сделки и определить, на что обратить внимание дальше.

## Технологии

- **Python**
- **FastAPI**
- **Pydantic**
- **GigaChat** — анализ клиентской коммуникации
- **Yandex SpeechKit** — распознавание аудио
- **Bitrix24 REST API** — работа с CRM
- **Bitrix24 Webhooks** — запуск обработки по событиям
- **pytest** — тестирование бизнес-логики

## Структура проекта

```text
app/
├── analyzer.py          # AI-анализ коммуникации
├── action_engine.py     # определение следующего действия
├── scorer.py            # scoring и качество лида
├── merger.py            # накопление состояния
├── pipeline.py          # основной qualification pipeline
├── models.py            # Pydantic-модели
├── profile.py           # загрузка профилей бизнеса
├── bitrix.py            # Bitrix24 REST API
├── bitrix_writer.py     # запись результата в CRM
├── openline.py          # работа с Open Line
├── speech_to_text.py    # распознавание аудио
├── speechkit.py         # интеграция с Yandex SpeechKit
└── main.py              # FastAPI-приложение

profiles/
└── <business_profile>/
    └── profile.json     # профиль и правила квалификации

tests/                   # тесты qualification pipeline и бизнес-логики
```

## Запуск

### 1. Установить зависимости

```bash
pip install -r requirements.txt
```

### 2. Создать `.env`

```env
GIGACHAT_CREDENTIALS=...
BITRIX_WEBHOOK_URL=...
YANDEX_API_KEY=...
YANDEX_FOLDER_ID=...
```

### 3. Запустить API

```bash
python -m uvicorn app.main:app --host 0.0.0.0 --port 8000
```

### 4. Запустить тесты

```bash
python -m pytest -q tests
```

## Демо

Основной сценарий демонстрирует квалификацию сделки внутри Bitrix24:

```text
Коммуникация клиента
        ↓
AI извлекает данные
        ↓
Сделка постепенно дополняется
        ↓
Qualification Score меняется
        ↓
AI определяет Intent и Missing Data
        ↓
Менеджер получает Next Step
```

Демо показывает не идеального «готового» лида, а реальный процесс, в котором квалификация становится точнее по мере появления новой информации.

## Статус проекта

MVP реализован и протестирован на реальной интеграции с Bitrix24.

Проект демонстрирует полный контур: **AI-анализ → накопление состояния → бизнес-правила → scoring → рекомендация действия → запись результата в CRM**.
